## Responsive + Interaction Contract

- Layout priority: desktop-first, then adaptive to tablet/mobile.
- Breakpoints: desktop `>=1024px`, tablet `768-1023px`, mobile `<768px`.
- Keyboard baseline (POS domain): typing letters triggers product search; `ArrowUp/ArrowDown` move active-item focus; `ArrowLeft/ArrowRight` switch list focus; `Enter` processes selected item.
- Session UX baseline: user re-enters app directly when session is valid; idle timeout warning should appear before 6-hour cut-off.

---

## Localization Contract

- Language: Bahasa Indonesia by default across all user-facing UI.
- Currency: IDR formatted without decimals.
- Locale: `id-ID` for all formatters.
- Timezone: `Asia/Jakarta`.
- Datetime display format: `dd-mm-yyyy hh:mm:ss`.
