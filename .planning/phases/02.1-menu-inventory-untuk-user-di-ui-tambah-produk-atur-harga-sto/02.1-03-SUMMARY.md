# 02.1-03 SUMMARY

## Objective
Menyelesaikan penyempurnaan Inventory UI dan data model produk agar mendukung:
- stok unit kecil dan unit besar yang terpisah,
- harga jual unit kecil dan unit besar yang berbeda,
- alur offline-first + sync yang tetap konsisten,
- form produk 2 kolom yang jelas antara produk satuan vs unit besar.

## Delivered
- Model produk diperluas untuk multi-unit terpisah:
  - `stok_saat_ini` (unit kecil),
  - `stok_unit_besar_saat_ini` (unit besar),
  - `harga_jual` (unit kecil),
  - `harga_jual_unit_besar` (unit besar).
- Event mutasi inventory ditambah `unit_mutasi` (`SMALL`/`LARGE`) agar stock in/out tidak konversi otomatis antar unit.
- Validasi API produk/sync diperbarui untuk field unit dan harga per unit.
- Hook local-first inventory diperbarui agar update stok berjalan per unit target.
- Form produk dipecah menjadi 2 panel:
  - kiri: Produk Satuan,
  - kanan: Unit Besar.
- Tampilan tabel produk menampilkan harga dan stok per unit.
