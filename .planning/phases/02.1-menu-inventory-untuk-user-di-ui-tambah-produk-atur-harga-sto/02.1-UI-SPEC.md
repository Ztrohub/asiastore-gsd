# Phase 02.1 - UI Design Contract

> Visual and interaction contract for inventory UI phase. This file locks layout, copy, spacing, and interaction decisions before planning and execution.

## Information Architecture

| Area | Contract |
|------|----------|
| Primary route | `/app/inventory` (inside authenticated shell) |
| Top-level layout | Single page with 2 tabs: `Produk`, `Stock In` |
| Product create interaction | `Tambah Produk` opens modal dialog |
| Product list presentation | Compact table with search, not cards |
| Post-submit behavior | Success toast + form reset, remain in current tab |

Hard rules:
- Do not split this phase into separate routes for product and mutation forms.
- Do not use product cards or image-oriented catalog patterns.
- Keep mutation forms local-first and fast (no blocking waits on sync round-trips).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f7f7f4` | App background and large neutral surfaces |
| Secondary (30%) | `#ffffff` / `#eef2e6` | Cards, tab panels, and sidebar surfaces |
| Accent (10%) | `#0b6e4f` + `#34d399` | Active tab, primary CTA, focus ring, positive status |

Accent reserved for:
- Active tab indicator

- Keyboard/focus guidance highlight
- Positive mutation result badge

Never use accent for:
- Body text
- Passive borders
- Non-interactive decoration

## Interaction Contract

### Tab behavior
- Default landing tab: `Produk`.
- Tab switch must preserve unsent draft values in other tabs during same session.
- Keyboard navigation between tabs must be possible with standard tab focus order.

### Produk tab
- `Tambah Produk` opens modal (`Dialog`) with fields:
  - Nama produk (required)
  - SKU (optional)
  - Harga jual (required, integer only)
  - Stok awal (optional integer)
- Harga input accepts raw digits while typing and formats to IDR on blur.
- Validation:
  - Harga min `100`
  - Harga max `999999999`
  - No decimal values
- Product table minimum columns:
  - Nama produk
  - Harga jual
  - Stok saat ini
  - Aksi (edit)

### Stock In tab
- Form must require product selection + quantity in.
- Submit writes local mutation event and shows success toast.
- After success: reset form, stay in `Stock In`.

### Adjustment stok (terintegrasi di Produk)
- Tidak ada tab `Stock Adjustment` terpisah.
- Perubahan data stok/konfigurasi dilakukan dari alur `Produk` (create/edit) agar operasi harian lebih ringkas.
- Perubahan stok tetap diproses local-first dan ikut jalur sinkronisasi yang sama.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (Produk modal) | `Simpan Produk` |
| Primary CTA (Stock In) | `Simpan Stock In` |
| Empty state heading | `Belum ada produk` |
| Empty state body | `Tambah produk pertama untuk mulai transaksi inventory.` |
| Error state | `Data belum valid. Periksa field yang ditandai lalu coba lagi.` |
| Destructive confirmation | `Batalkan perubahan`: `Perubahan belum disimpan akan hilang.` |

Microcopy rules:
- Keep sentences short and action-oriented.
- Prefer operational terms used by kasir/owner (`stok`, `harga`, `simpan`, `ubah`).
- Avoid ambiguous English-only labels in primary actions.

## Component Contract

Required existing primitives:
- `src/components/ui/table.tsx`
- `src/components/ui/dialog.tsx`
- `src/components/ui/input.tsx`
- `src/components/ui/button.tsx`
- `src/components/ui/badge.tsx`
- `src/components/ui/sonner.tsx`

Component-level rules:
- Reuse existing primitives first; do not introduce a second modal or table system.
- Keep row height compact (`TableHead h-10`, `TableCell p-2` baseline).
- Forms use single-column on mobile and dense two-column grouping only on desktop where readable.

## Responsive Contract

| Breakpoint | Contract |
|------------|----------|
| `<768px` | Tabs remain horizontal scrollable if needed; table can overflow-x with sticky headers off |
| `768-1023px` | Two-column form grouping allowed inside modal; table remains compact |
| `>=1024px` | Full table + search + action controls visible without collapsing key columns |

Do not hide critical actions (`Simpan`, `Ubah Harga`, tab switch) on any breakpoint.
