<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| product-search->cart-state | Untrusted cashier input selects products and mutates cart lines locally before any payment gate. |
| qty-dialog->stock-out-mutation | The qty dialog converts free-form numeric input into inventory-impacting stock deltas. |
| pos-route->inventory-cache | POS depends on cached product/stock data that may be stale until sync completes. |

</threat_model>
