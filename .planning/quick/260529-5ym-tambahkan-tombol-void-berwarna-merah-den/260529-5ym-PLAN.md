# Quick Task 260529-5ym: tambahkan tombol void berwarna merah dengan shortcut keyboard di tampilan PoS untuk menghapus semua item di keranjang dan membatalkan transaksi

## Scope

- Tambahkan tombol `Void` berwarna merah pada panel keranjang POS.
- Tambahkan shortcut keyboard `F10` untuk membatalkan transaksi aktif.
- Saat void dijalankan, kosongkan item keranjang, diskon transaksi, dan catatan transaksi lalu kembalikan fokus ke pencarian produk.

## Must Have

- Tombol `Void (F10)` terlihat di tampilan POS.
- Tombol aktif hanya saat keranjang berisi item.
- Shortcut `F10` bekerja saat tidak ada dialog modal yang sedang terbuka.
- Void mengembalikan POS ke state transaksi baru tanpa checkout.

## Verification

- Test UI POS membuktikan tombol void tampil, state keranjang reset, dan shortcut `F10` bekerja.
