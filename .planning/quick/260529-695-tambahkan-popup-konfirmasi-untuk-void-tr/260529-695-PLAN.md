# Quick Task 260529-695: tambahkan popup konfirmasi untuk void transaksi di PoS sebelum semua item keranjang dihapus

## Scope

- Tambahkan popup konfirmasi saat aksi `Void (F10)` dipicu dari tombol atau shortcut keyboard.
- Void baru dijalankan setelah user mengonfirmasi di dialog.
- Pertahankan alur keyboard-first agar konfirmasi bisa dijalankan tanpa mouse.

## Must Have

- Klik tombol `Void (F10)` menampilkan popup konfirmasi.
- Menekan `F10` menampilkan popup konfirmasi yang sama.
- Transaksi belum dibersihkan sebelum user menekan tombol konfirmasi.
- Setelah konfirmasi, item keranjang, diskon, dan catatan transaksi dibersihkan.

## Verification

- Test POS membuktikan dialog tampil, cancel tidak menghapus transaksi, dan konfirmasi baru menjalankan void.
