# Quick Task 260529-7hm: menekan tombol del di keyboard saat modal edit qty keranjang muncul seharusnya menghapus item dari keranjang dan menampilkan pesan konfirmasi menghapus item, bukan menghapus value field qty. Di beberapa modal konfirmasi seperti hapus item dan cetak receipt fokus ditandai dengan border putih (hapus/print) tapi terdapat cursor fokus default berwarna hijau di sekitar tombol lainnya (batal/lewati) sehingga membingungkan user. Hilangkan cursor default agar tidak membingungkan user.

## Scope

- Ubah shortcut `Delete` di modal edit item keranjang agar membuka konfirmasi hapus item.
- Hilangkan focus ring default pada tombol-tombol modal konfirmasi yang sudah memakai indikator fokus putih.

## Must Have

- Saat modal edit item keranjang terbuka, menekan `Delete` memunculkan dialog `Hapus item?`.
- `Delete` tidak lagi menghapus isi field qty.
- Modal `Hapus item?` dan `Cetak receipt?` hanya menampilkan indikator fokus putih kustom tanpa focus ring default tambahan.

## Verification

- Test POS membuktikan `Delete` di modal edit item membuka konfirmasi hapus.
- Test modal konfirmasi membuktikan tombol aksi memiliki class override untuk mematikan focus ring default.
