# Quick Task 260529-7uo: buat cursor putih global di semua modal dialog. Buat agar user dapat berpindah tombol dialog dengan menekan arrow kiri-kanan

## Scope

- Samakan indikator fokus putih pada tombol aksi di semua modal dialog aplikasi yang memakai `Dialog`.
- Tambahkan navigasi tombol dialog dengan `ArrowLeft` dan `ArrowRight` tanpa merusak perilaku input yang sudah ada.

## Must Have

- Semua tombol aksi modal memakai override focus ring yang konsisten agar tidak muncul cursor default tambahan.
- Setiap modal menampilkan aksi default dengan indikator putih yang sama.
- Saat fokus berada pada area aksi/non-input dialog, `ArrowLeft` dan `ArrowRight` memindahkan pilihan tombol.
- Dialog yang punya input tetap mempertahankan shortcut input yang sudah ada, termasuk pemilihan unit di modal qty.

## Verification

- Test dialog POS membuktikan white cursor dan navigasi kiri/kanan bekerja pada modal qty, edit item, payment, receipt, remove, dan warning/konfirmasi terkait.
- Test inventory dialog membuktikan style white cursor global diterapkan ke modal non-POS yang juga memakai `Dialog`.
