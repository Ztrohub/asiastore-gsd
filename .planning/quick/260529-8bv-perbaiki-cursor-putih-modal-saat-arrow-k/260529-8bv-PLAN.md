# Quick Task 260529-8bv: perbaiki cursor putih modal saat arrow kiri-kanan dipindah bolak-balik

## Scope

- Perbaiki sinkronisasi fokus tombol modal dan cursor putih saat navigasi `ArrowLeft`/`ArrowRight`.
- Tangani regresi pada modal receipt prompt dan konfirmasi hapus item keranjang yang kehilangan indikator saat fokus dipindah bolak-balik.

## Must Have

- Setelah pindah dari tombol utama ke tombol sekunder lalu kembali lagi, white cursor tetap muncul pada tombol yang aktif.
- Navigasi keyboard memindahkan fokus DOM aktual ke tombol target, bukan hanya state seleksi internal.
- Modal receipt prompt dan remove dialog tetap bisa dieksekusi dengan `Enter` setelah fokus dipindah.

## Verification

- Test receipt prompt membuktikan fokus dan cursor putih bisa bolak-balik antara `Print` dan `Lewati`.
- Test remove dialog membuktikan fokus dan cursor putih bisa bolak-balik antara `Hapus` dan `Batal`.
