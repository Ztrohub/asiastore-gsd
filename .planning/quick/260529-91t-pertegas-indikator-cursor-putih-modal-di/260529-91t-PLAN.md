# Quick Task 260529-91t: pertegas indikator cursor putih modal dialog agar terlihat jelas

## Scope

- Pertegas indikator visual tombol aktif di modal dialog yang sekarang terlihat hilang di UI nyata.
- Samakan cue visual modal dengan pattern selection yang sudah dipakai di tabel produk dan keranjang.

## Must Have

- Tombol aktif di modal tetap punya white cursor yang jelas saat dialog dibuka.
- Tombol outline aktif punya cue visual tambahan selain ring luar agar tetap terlihat pada latar popup terang.
- Navigasi `ArrowLeft` dan `ArrowRight` tetap memindahkan fokus dan indikator aktif secara sinkron.

## Verification

- Test receipt prompt dan remove dialog membuktikan tombol aktif memiliki class visual yang lebih tegas.
- Regression test keyboard dialog tetap lulus setelah perubahan style helper.
