# Quick Task 260529-9cf: tampilkan kembalian besar di modal cetak receipt berdasarkan uang diterima

## Scope

- Tampilkan nominal kembalian dengan font besar pada modal `Cetak receipt?`.
- Gunakan data transaksi hasil checkout, bukan hitung ulang dari UI.

## Must Have

- Untuk transaksi tunai, modal receipt menampilkan nominal `change_amount` yang harus dikembalikan ke customer.
- Nilai kembalian ditampilkan lebih menonjol daripada copy modal biasa.
- Untuk pembayaran non-tunai, blok kembalian tidak tampil.

## Verification

- Test receipt prompt membuktikan nominal kembalian cash tampil besar dan terformat IDR.
- Test receipt prompt membuktikan blok kembalian tidak tampil untuk transaksi transfer.
