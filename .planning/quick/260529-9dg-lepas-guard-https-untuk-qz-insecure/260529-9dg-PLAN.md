# Quick Task 260529-9dg: lepas guard https untuk qz insecure

## Scope

- Hapus penolakan runtime yang memblokir koneksi QZ Tray saat webapp berjalan di `HTTPS` tetapi `qzUseSecure=false`.
- Pertahankan toggle dan daftar port `WS/WSS` yang sudah ada; koneksi tetap mengikuti setting user.

## Must Have

- `connectQzTray()` tidak lagi melempar error hanya karena protocol webapp `https:`.
- Saat `qzUseSecure=false`, payload koneksi ke `qz.websocket.connect()` tetap memakai `usingSecure: false`.
- Perilaku konfigurasi printer lain tidak berubah.

## Verification

- Test `qz-client` membuktikan koneksi tetap dibuat saat `window.location.protocol === "https:"` dan `qzUseSecure=false`.
- Test `qz-client` membuktikan opsi `usingSecure: false` diteruskan ke QZ websocket.
