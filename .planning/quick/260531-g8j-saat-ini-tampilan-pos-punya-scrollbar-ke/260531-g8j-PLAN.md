# Quick Task 260531-g8j: saat ini tampilan POS punya scrollbar ketika di layar desktop PC. Buat tampilan PoS selalu cukup dalam satu layar tanpa scroll ketika di layar ukuran besar tanpa mengubah struktur dan fungsionalitas apapun.

## Scope

- Rapikan layout halaman POS khusus untuk viewport desktop besar agar seluruh permukaan utama muat di dalam tinggi viewport tanpa scroll halaman browser.
- Pertahankan struktur UI yang ada: header POS, area pencarian, tabel produk, panel keranjang, catatan transaksi, dan seluruh dialog tetap ada dan berfungsi sama.
- Jika konten perlu tetap bisa digulir, pindahkan overflow ke area internal seperti daftar produk atau daftar item keranjang, bukan ke halaman utama desktop.

## Must Have

- Pada desktop besar, halaman `/app/pos` tidak menghasilkan scrollbar vertikal di level dokumen/browser saat kondisi awal POS ditampilkan.
- Flow keyboard POS, tombol checkout, dan catatan transaksi tidak berubah perilaku.
- Tampilan tablet/mobile tidak direstruktur ulang; perubahan hanya memperketat layout desktop besar.

## Verification

- Tambahkan regresi Playwright yang memastikan tinggi dokumen POS desktop tidak melebihi `window.innerHeight`.
- Jalankan spec e2e POS yang baru/terkait setelah perubahan.
- Jalankan lint pada file React/Next yang disentuh.
