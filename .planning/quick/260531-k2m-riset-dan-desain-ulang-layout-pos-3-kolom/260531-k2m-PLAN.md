# Quick Task 260531-k2m: riset dan desain ulang layout POS 3 kolom agar keranjang dan daftar produk tetap lega tanpa scrollbar halaman desktop

## Scope

- Audit akar masalah layout POS desktop yang membuat area keranjang mengecil setelah halaman utama dipaksa tidak punya scrollbar.
- Riset pola adaptive layout yang relevan untuk POS keyboard-first dengan daftar padat dan checkout cepat.
- Dokumentasikan desain yang sudah disetujui: desktop 3 kolom, tablet landscape 2 kolom dengan ringkasan di bawah keranjang, mobile 1 kolom.
- Kunci invariants keyboard flow, internal scroll rules, dan verifikasi responsif sebelum implementasi dimulai.

## Must Have

- Desktop besar tetap tidak memiliki scrollbar di level halaman/browser.
- Kolom produk dan kolom keranjang masing-masing memiliki internal scroll sendiri pada desktop dan tablet landscape.
- Kolom ringkasan/aksi berisi diskon transaksi, subtotal, total, catatan transaksi, serta tombol `Tunai`, `Transfer`, dan `Void`.
- Shortcut dan keyboard flow POS tidak berubah.
- Ada spec tertulis yang cukup konkret untuk langsung dipakai di tahap planning dan implementasi.
