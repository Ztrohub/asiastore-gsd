# Quick Task 260601-g7p: tambahkan menu transaksi untuk melihat daftar transaksi dalam bentuk tabel expandable untuk melihat detail item transaksi. Tabel berbentuk pagination sehingga query pada table transaksi lokal hanya page tersebut sehingga tidak berat. Menu transaksi memiliki filter range tanggal dengan default adalah hari ini. Sebelum mengerjakan menu ini, pastikan proses sync transaksi dari database remote ke database lokal sudah benar.

## Scope

- Tambahkan jalur sinkronisasi transaksi POS dari server ke database lokal dengan cursor yang aman untuk transaksi yang tersinkron terlambat.
- Sediakan query riwayat transaksi lokal yang mengambil hanya halaman aktif untuk rentang tanggal terpilih.
- Tambahkan menu dan halaman `Transaksi` berisi tabel transaksi dengan filter tanggal default hari ini, navigasi halaman, dan detail item expandable.

## Must Have

- Pull sync transaksi remote ke lokal tidak bergantung pada `client_timestamp`, sehingga transaksi lama yang baru sinkron ke server tetap ikut terambil.
- Query riwayat transaksi lokal hanya mengambil data untuk halaman aktif beserta indikator apakah masih ada halaman berikutnya.
- Halaman transaksi default ke rentang tanggal hari ini, bisa mengubah tanggal awal/akhir, dan menampilkan detail item transaksi tanpa meninggalkan tabel.

## Verification

- Tambahkan test kontrak untuk pull sync transaksi remote ke lokal.
- Tambahkan test kontrak untuk query lokal berpaginasi dan tampilan tabel expandable transaksi.
- Jalankan Vitest pada file yang disentuh dan ESLint pada source/test baru yang relevan.
