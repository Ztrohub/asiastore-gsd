# Quick Task 260609-n01: perbaiki server sync inventory agar menerima delta_qty desimal dan siapkan alur migrasi produksi

## Goal

Memperbaiki server replay inventory agar payload `delta_qty` desimal dari client tidak lagi ditolak, stok hasil replay tetap presisi, dan perubahan database production memiliki alur rollout yang aman.

## Must Haves

- Endpoint `/api/sync/inventory-deltas` menerima `delta_qty` desimal selama nilainya finite dan bukan nol.
- Replay inventory server tidak menghilangkan pecahan stok saat membaca stok saat ini dan menerapkan delta.
- Skema Prisma mendukung penyimpanan pecahan pada event mutasi dan stok produk server.
- Ada catatan rollout yang menjelaskan perubahan skema untuk production tanpa memutus data existing.

## Tasks

1. Tambahkan regresi test untuk validator payload decimal dan replay stok decimal di server.
2. Refactor validasi payload sync ke helper terpusat dan longgarkan aturan `delta_qty` dari integer menjadi finite non-zero.
3. Ubah replay stok server dan skema Prisma ke tipe float untuk kolom qty/stok yang harus menampung pecahan, lalu verifikasi dengan test, lint, dan `prisma validate`.
