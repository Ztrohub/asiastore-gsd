# Quick Task 260610-f09: ketika saya build terdapat type error

## Goal

Memperbaiki type error yang membuat `pnpm build` gagal tanpa mengubah perilaku replay stok inventory.

## Must Haves

- `pnpm build` lolos tanpa error TypeScript pada `src/lib/db/inventory-replay.ts`.
- Perbaikan hanya menyentuh akar masalah narrowing tipe pada normalisasi stok persisted.
- Logika normalisasi tetap aman untuk nilai `null`, `undefined`, dan angka non-finite.

## Tasks

1. Gunakan kegagalan `pnpm build` saat ini sebagai reproduksi merah untuk error type di `normalizePersistedStock`.
2. Samakan guard `normalizePersistedStock` dengan pola narrowing numerik yang sudah dipakai di codebase.
3. Jalankan verifikasi segar setelah perubahan untuk memastikan build produksi kembali hijau.
