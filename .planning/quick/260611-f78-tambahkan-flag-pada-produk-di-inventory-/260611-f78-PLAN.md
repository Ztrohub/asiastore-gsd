# Quick Task 260611-f78: tambahkan flag pada produk di inventory untuk metadata marketplace

## Goal

Menambahkan flag produk marketplace di inventory beserta field metadata khusus marketplace tanpa merusak alur produk existing, offline cache, atau sinkronisasi production.

## Must Haves

- Produk inventory bisa ditandai sebagai dijual di marketplace lewat checkbox di form tambah/ubah produk.
- Jika checkbox marketplace aktif, user wajib mengisi nama produk marketplace, id produk marketplace, dan id SKU marketplace.
- Jika checkbox marketplace nonaktif, metadata marketplace tidak ikut tersimpan dan data lama tetap aman.
- Perubahan struktur database dilakukan lewat Prisma migration yang aman untuk data production existing.
- Payload sync server/local dan cache offline tetap kompatibel dengan produk lama yang belum punya metadata marketplace.

## Tasks

1. Tambahkan failing tests untuk validasi payload marketplace di API, submit form inventory, dan normalisasi katalog offline saat flag marketplace dinonaktifkan.
2. Implementasikan field marketplace di model Prisma, alur server catalog, cache offline, dan form inventory dengan normalisasi yang clear-safe.
3. Buat Prisma migration untuk kolom marketplace baru lalu jalankan verifikasi segar pada test, lint, dan build yang relevan.
