# Quick Task 260611-h6w: badge marketplace icon-only di kanan nama produk

## Goal

Mengubah badge marketplace pada daftar inventory menjadi badge kecil icon-only di sebelah kanan nama produk, tanpa teks `Marketplace` yang terlihat.

## Must Haves

- Teks `Marketplace` dihapus dari badge produk inventory.
- Badge tetap menggunakan ikon `Store` dalam gaya kecil `outline`.
- Badge hanya tampil untuk produk marketplace.
- Badge berada di sebelah kanan nama produk.
- Badge tetap memiliki label aksesibel seperti `Produk marketplace`.
- Perubahan tidak mengubah alur search, filter, API, atau database.

## Tasks

1. Ubah test kontrak inventory agar memverifikasi badge icon-only, label aksesibel, dan posisi badge di kanan nama produk.
2. Implementasikan susunan nama produk + badge baru di `ProductTable`.
3. Jalankan verifikasi segar pada test inventory, lint file terkait, dan build aplikasi.
