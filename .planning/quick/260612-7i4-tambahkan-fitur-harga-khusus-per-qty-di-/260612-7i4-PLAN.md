# Quick Task 260612-7i4: harga khusus per qty otomatis di POS

## Goal

Menambahkan harga khusus per qty pada master produk yang otomatis dipakai di transaksi POS, tampil sebagai breakdown item di POS dan receipt, tetap sinkron offline, dan menggunakan Prisma migration untuk perubahan struktur database.

## Must Haves

- Master produk mendukung rule harga khusus per unit jual dengan qty `0.1` sampai `0.9`.
- Resolver harga memakai prioritas exact-first, lalu kombinasi rule terbaik, lalu sisa prorata harga dasar.
- POS menampilkan breakdown seperti `1.1 x 10.000` dan `0.5 x 6.000`.
- Receipt dan histori transaksi menampilkan breakdown yang sama dari snapshot transaksi.
- Produk, transaksi, dan sync offline membawa data harga khusus yang diperlukan.
- Semua perubahan struktur database dibuat lewat Prisma migration.

## Tasks

1. Tambahkan shared special-price contract dan resolver exact-first dengan test unit baru.
2. Persist rule harga khusus ke Prisma schema, migration, product catalog server, dan validasi route produk.
3. Hubungkan special-price rules ke cache Dexie, sync katalog produk, dan form master produk.
4. Terapkan resolver ke cart POS, checkout, dialog edit item, dan breakdown tampilan PoS.
5. Persist snapshot pricing ke histori transaksi, sync POS, detail transaksi, dan receipt.
6. Jalankan test, lint, Prisma generate, build, lalu tulis summary quick task.
