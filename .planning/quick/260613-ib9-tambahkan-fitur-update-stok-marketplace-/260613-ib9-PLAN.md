# Quick Task 260613-ib9: update stok marketplace dari template xlsx

## Goal

Menambahkan tab `Marketplace` di halaman inventori untuk upload template `.xlsx`, mengisi kolom stok berdasarkan data marketplace di katalog lokal, menyimpan konfigurasi export di browser client, lalu mengunduh file hasil tanpa menyentuh backend atau data inventory aplikasi.

## Must Haves

- Tab baru bernama `Marketplace` muncul tanpa merusak flow `Produk` dan `Stock In`.
- File diproses client-only pada sheet pertama saja.
- Row sebelum `start row` tidak disentuh.
- User bisa mengubah kolom ID Produk, ID SKU, kolom Stok, `start row`, dan persentase stok.
- Konfigurasi export tersimpan lokal di browser client dan dimuat ulang otomatis.
- Pencocokan memakai `marketplace_product_id` + `marketplace_sku_id`.
- Jika match, tulis `ceil(stok_saat_ini * persentase / 100)`.
- Jika mismatch, tulis `0`.
- Tidak ada write ke backend, Prisma, Dexie, atau sync queue.

## Tasks

1. Tambahkan util workbook dan config persistence lokal dengan test unit untuk parsing kolom, perhitungan stok, mismatch, dan row protection.
2. Tambahkan komponen tab `Marketplace`, form upload/config, summary hasil, dan integrasikan ke `InventoryTabs` dengan test UI inventory.
3. Tambahkan dependency `.xlsx`, validasi input/fallback download, lalu jalankan test, lint, dan build final.
